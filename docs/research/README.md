# Research documents

[Toward spatial audio through matter](modal_reference/paper.md) is the first working
technical paper. It accompanies the dry modal reference study and includes seven
verified references, derivations, computed figures, limitations and a reproducible
validation procedure.

[Configurable dry-structure experiments](modal_reference/parameter_experiments.md)
extends it with eight parameter variations, physical-unit comparisons, saved
configuration replay and explicit solver capability checks.

[Decisions and assumptions](modal_reference/decisions.md) records what the project
owner selected, what is provisional and what remains open before modeling the
curved, water-filled basin. Computed results do not substitute for measurements.
